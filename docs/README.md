# Team documentation

This folder contains the contributor and design guides, active plans, and
durable knowledge for KL&A Tools. The [agent reference index](../docs.ai/README.md)
defines documentation ownership and links release governance in `docs.ai/`.
Coding guides, reviews, decisions, and handoffs are indexed under `knowledge/`.

| Area | Purpose |
| --- | --- |
| [Contributor guide](CONTRIBUTING.md) | Roles, day-to-day changes, validation, and where to get help. |
| [Design-system guide](DESIGNSYSTEM.md) | Living UI styles, resources, and component inventory. |
| [Plans](plans/README.md) | Active implementation plans and task-ledger conventions. |
| [Knowledge](knowledge/README.md) | Reusable knowledge, significant decisions, and new handoff snapshots. |

The root [README](../README.md) describes the extension and its commands.
