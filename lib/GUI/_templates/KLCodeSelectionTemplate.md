# Retired Selection template

The separate **Template - Selection** example and its XAML were removed on
2026-10-30 at the owner's request. This page remains only as a navigation target
for historical documentation links; it is not an active implementation guide.

Use the actual shared [Selection dialog](../dialogs/SelectionDialog.xaml) and
[shared dialog API guide](../dialogs/README.md) as the canonical references.
In UI Gallery, search **Shared dialog** for Sheets, Revisions, Open Documents,
List Single and List Multiple previews.

The [remaining reference templates](README.md) are Form, Options and Review.
[DESIGNSYSTEM.md](../../../docs/DESIGNSYSTEM.md) owns current visual rules;
the [consolidation plan](../../../docs/plans/custom-window-consolidation.md)
owns task and acceptance status. Earlier Selection geometry and decisions remain
in the [dated refinement record](../../../docs/knowledge/reviews/design-system/2026-10-27-main-template-refinement.md).
