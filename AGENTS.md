# KLCode.pyRevit agent entry point

Read [the detailed agent guidance](docs.ai/AGENTS.md) before changing this
pyRevit extension. Keep changes focused, preserve unrelated work, check the
final diff, and run the narrowest relevant validation.

`docs.ai/` holds agent guidance, technical audits, and implementation handoffs.
`docs/` holds the human contributor and release guides and decision records.
The authoritative release workflow is [RELEASING.md](docs/releasing/RELEASING.md).

The development branch is `master-dev`. Ordinary contributions use a topic
branch and a PR into `master-dev`; the release owner has the documented direct
push exception for release preparation and post-release synchronization.
Releases reach `main` only through a `master-dev` to `main` PR personally merged
by the release owner.
